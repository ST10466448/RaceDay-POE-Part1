RaceDay

 Project Overview

RaceDay is a race event management system designed to help organisers manage race events, event categories, participant enrolments and race results.

The system has two main user roles:

Organiser – Can create, edit and delete events, manage event categories, view participant enrolments and record participant results.
Participant – Can create an account, browse available events, enter an event category, view their enrolments and track their race results.

 Part 1

Part 1 of the RaceDay project consists of the following sections:

 Section A – Entity Relationship Diagram

The ERD was created to show the structure of the RaceDay database.

The ERD contains six main entities:

1. Users
2. Routes
3. Events
4. Event Categories
5. Entries
6. Results

The ERD shows the attributes, primary keys, foreign keys and relationships between the entities.


Section B – API Endpoint Plan

The API Endpoint Plan defines the endpoints that will be used to develop the RaceDay API in Part 2.

The planned API includes endpoints for:

- User registration
- User login
- User profiles
- Events
- Event categories
- Event entries
- Race results

 Section C – SQL Database

The RaceDay database was created using Microsoft SQL Server.

The database contains the following tables:

- `Users`
- `Routes`
- `Events`
- `EventCategories`
- `Entries`
- `Results`

The database uses:

- Primary keys
- Foreign keys
- Unique constraints
- Check constraints
- Default values
- Sample data
